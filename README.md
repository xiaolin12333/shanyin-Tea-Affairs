## 项目介绍

“山隐茶事”是一个以中国茶文化为主题的生活方式网站。项目以“一盏茶，见山河”为核心表达，从茶山风土、制茶工艺、茶类知识、风味数据到茶席体验，构建了一套兼具东方审美与现代交互方式的数字茶事体验。

网站采用无需后端的纯前端实现，用户既可以浏览茶文化内容、探索产区地图与数据图谱，也可以使用本地 AI 茶事顾问获取冲泡建议，并体验搜索、收藏、预约、社区活动等完整交互闭环。项目注重内容可读性、视觉层次、响应式布局与无障碍体验，力求让用户在自然、克制而有温度的界面中认识中国茶。

### 主要功能

- **茶文化内容**：展示采青、萎凋、杀青、揉捻、焙火、成茶等制茶环节。
- **山河茶图**：以互动地图呈现景迈山、西湖龙井、武夷山等代表性茶区。
- **数据图谱**：通过茶类数据、风味雷达与产区趋势，帮助用户理解茶的风味特征。
- **AI 茶事顾问**：根据饮茶场景、水温、投茶量、出汤时间等关键词，生成茶事建议。
- **茶友社区与茶席体验**：支持活动筛选、活动收藏、加入茶席和茶席预约演示。
- **茶集与个人茶库**：支持茶类筛选、茶样收藏、文章阅读及浏览状态记录。
- **全站搜索**：支持通过搜索入口或 `Ctrl/Cmd + K` 快速查找页面与内容。
- **响应式体验**：适配桌面端、平板与移动端，并提供键盘操作和减少动态效果支持。

## 技术架构

项目采用“原生前端 + 单页应用”的轻量化架构，不依赖前端框架、构建工具或后端服务，可直接部署到任意静态网站托管平台。

```text
浏览器
  └─ index.html
      ├─ styles.css ── 视觉主题 / 响应式布局 / 动效
      └─ app.js
          ├─ Hash 路由 ── 页面模板切换
          ├─ 业务数据 ── 茶区、茶类、活动、文章
          ├─ 交互逻辑 ── 搜索、筛选、收藏、预约
          ├─ AI 规则引擎 ── 本地茶事建议生成
          └─ localStorage ── 演示状态持久化
```

### 技术选型

| 层级 | 技术实现 | 说明 |
| --- | --- | --- |
| 页面结构 | HTML5 | 使用语义化结构、ARIA 属性与内联 SVG 图标 |
| 视觉样式 | CSS3 | 自定义属性、Flexbox、Grid、`clamp()` 响应式字号、动画与媒体查询 |
| 交互逻辑 | 原生 JavaScript（ES6+） | 使用模块化 IIFE 组织代码，无需第三方运行时 |
| 页面路由 | Hash 路由 | 通过 `hashchange` 切换页面模板，刷新后仍可定位当前页面 |
| 状态管理 | JavaScript 状态对象 + `localStorage` | 保存当前账户、收藏、活动和预约等演示状态 |
| 数据可视化 | HTML + CSS + JavaScript | 使用动态模板、图表和雷达图呈现茶类与风味数据 |
| AI 能力 | 本地规则引擎 | 基于饮茶场景与关键词匹配生成建议，无需 API Key |
| 素材管理 | 本地静态资源 | 图片统一存放于 `assets/`，并记录来源与授权信息 |

### 目录结构

```text
.
├─ index.html            # 页面骨架、品牌入口、导航与公共弹层
├─ styles.css            # 全站视觉主题、组件样式与响应式规则
├─ app.js                # 路由、数据、页面渲染和交互逻辑
├─ assets/               # 茶山、茶席、制茶过程与活动图片
├─ output/               # 项目页面效果截图
├─ .design-work/         # 设计工作文件与图片授权记录
└─ README.md             # 项目说明文档
```

### 架构特点

- **零依赖、易部署**：无需安装 npm 包，不需要编译，可直接作为静态网站发布。
- **前后端解耦的演示设计**：登录、购买、收藏、预约等功能均在前端完成，适合赛事演示和原型验证。
- **数据驱动渲染**：茶区、茶类、活动与文章数据集中定义，由 JavaScript 模板统一渲染。
- **响应式与无障碍**：针对不同屏幕尺寸设置断点，提供语义化标签、键盘快捷键及 `prefers-reduced-motion` 适配。
- **本地隐私优先**：演示状态只保存在当前浏览器，不会上传至服务器。

## 安装运行指南

### 环境要求

- 现代浏览器：推荐使用最新版 Chrome、Edge、Firefox 或 Safari。
- Python 3（可选）：用于启动本地静态文件服务器。
- 无需安装 Node.js、npm、数据库或后端环境。

### 快速运行

**方式一：直接打开**

在文件管理器中双击 `index.html`，即可使用默认浏览器预览网站。

**方式二：本地服务器（推荐）**

进入项目根目录并启动静态服务器：

```powershell
cd <项目目录>
python -m http.server 4173
```

如果 Windows 环境中的 `python` 命令不可用，可改用：

```powershell
py -m http.server 4173
```

macOS 或 Linux 环境可使用：

```bash
cd <项目目录>
python3 -m http.server 4173
```

启动后访问：

```text
http://127.0.0.1:4173/
```

按 `Ctrl + C` 停止本地服务器。

### 演示账号与操作

- 在登录界面输入任意有效手机号和不少于 6 位字符的密码即可进入；也可选择“暂不登录，先逛一逛”。
- 使用 `Ctrl/Cmd + K` 可打开全站搜索。
- 登录、预约、购买和收藏均为前端演示，不会产生真实账户、支付或线下席位。
- 如需恢复初始演示状态，可在浏览器开发者工具中执行：

```javascript
localStorage.removeItem("shanyin-tea-demo-v1");
location.reload();
```

### 常见问题

- **直接打开后部分浏览器行为不一致**：请优先使用本地服务器方式运行。
- **端口被占用**：将 `4173` 改为其他可用端口，并同步修改访问地址。
- **页面没有加载最新内容**：使用 `Ctrl/Cmd + Shift + R` 强制刷新浏览器缓存。
